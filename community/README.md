# Community recipes — UNVERIFIED

⚠️ **Nothing in this folder has been reviewed by anyone.**

Files here were submitted by the community and published automatically, without any fact-check or safety check by the maintainer. They may be wrong, outdated, or malicious. In particular, a recipe here might tell you to send credentials or private data somewhere you should not.

**Use at your own risk.** Before following anything in this folder:

- Verify every endpoint, host and scope against the provider's official documentation yourself.
- Never send API keys, tokens or personal data to any destination that is not the provider's own API endpoint.
- If a recipe works and you have verified it, consider submitting it to `recipes/` via pull request so it can join the verified set.

The verified, reviewed recipes live in [`recipes/`](../recipes/).
