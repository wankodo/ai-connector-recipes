AI Agent Connector Recipes & Field Notes

AIエージェントのためのコネクタレシピと試行錯誤の記録 — API連携の手順、既知の壁（ブロッカー）と回避策

AIエージェントが読んで、そのままコネクタを再現できるように作ったレシピ集と、連携作業でぶつかった壁と回避策の記録（フィールドノート）です。各レシピには、公式ドキュメントで検証したAPIホスト・エンドポイント・OAuth情報・人間側のセットアップ手順・つまずきポイントをまとめています。認証情報そのものは含まれません（各自の鍵は各自の安全な方法で登録してください）。

AIエージェントへ

まず機械可読な目次 index.json を取得してください。各レシピのMarkdownへのリンクと、既知のブロッカーが入っています。

レシピ一覧

レシピはステータスの「札」で4つに分類しています。作れる（そのまま構築に行ける）／公式コネクタあり（自作せず公式を使う）／条件付き（着手前に条件を読む）／不可（試すだけ時間の無駄）。棚自体は一枚のまま、札で並び分けています。

作れる

Discord

Markdown版（AI向け原版）

Discord API v10。Botトークンで、Botが招待されたサーバー内のチャンネル読み書きなどを行う。

公式リンク：公式ドキュメント（Discord Developers）

状態：作れる（Botトークン方式。Museへの登録自体は未検証）。個人アカウントの自動化（セルフボット）は規約禁止で停止対象。

freee（会計）

Markdown版（AI向け原版）

会計freee API。仕訳・取引先・レポートなどの読み書き。自社用プライベートアプリなら審査なしで作れる。

公式リンク：公式開発者ポータル（freee）

状態：作れる。認可・トークン・取消が全て同一ホスト（accounts.secure.freee.co.jp）で、単一ドメイン規則に当たらない。壁は運用側：リフレッシュトークンが90日・単回使用ローテーション。公開配布は審査制（約1〜2か月）。

Google Search Console

Markdown版（AI向け原版）

Search Console API。検索パフォーマンス、サイトマップの取得状況、URL検査の読み取り。

状態：作れる（サービスアカウントが使えるのが鍵。プロパティにサービスアカウントのメールを追加すれば、ユーザーOAuthなしで読める）。Museの自作OAuth登録だけがドメイン跨ぎで不可。

マネーフォワード（クラウド）

Markdown版（AI向け原版）

マネーフォワード クラウドAPI v3。クラウド会計の仕訳・勘定科目・レポートなど。アプリポータルの利用開始が前提。

状態：作れる（クラウド会計APIは2026年3月から全プラン公開。認可・トークンとも同一ホスト）。ただし家計簿の「マネーフォワード ME」は公開API自体がなく、そちらは不可。

Notion

Markdown版（AI向け原版）

Notion API。内部インテグレーションのトークンで、共有されたページ／データベースを検索・読み書きする。

公式リンク：公式ドキュメント（Notion Developers）

状態：作れる（内部インテグレーショントークン方式・見込み。登録自体は未検証）。壁は共有モデル：共有されたページ／DBしか見えず、未共有は「存在しない」ように見える。

Stripe

Markdown版（AI向け原版）

Stripe API。制限付きキー（rk_）で顧客・支払い・請求・残高などを読み取り中心に扱う。

公式リンク：公式MCPドキュメント（Stripe）

状態：作れる（APIキー方式・見込み。登録自体は未検証）。決済の実行は不可逆なので書き込みは人の承認が前提。ライブ利用には事業情報の検証・有効化（KYC）が必須。公式MCP経由の公式コネクタも別途ある。

公式コネクタあり

Facebook

Markdown版（AI向け原版）

Graph API／Pages API。ページの投稿・コメント・インサイトなど。現行APIはページ中心で、個人プロフィールへのアクセスは限定的。

公式リンク：公式ドキュメント（Meta for Developers）

状態：公式コネクタあり（自作不要）。自作する場合は認可（www.facebook.com）とトークン（graph.facebook.com）のドメイン分離で登録不可、APIキー代替もなし。

GitHub

Markdown版（AI向け原版）

GitHub REST API。リポジトリ・Issue・プルリクエストの読み書き。

公式リンク：公式MCPサーバー（GitHub）

状態：公式コネクタあり（GitHub MCPベース、接続・実利用中）。ただしコネクタ経由ではリポジトリ新規作成と .github/workflows/ への push が403になる（ウェブ画面で代替）。

公式リンク：公式ドキュメント（Drive API）

Google Sheets

Instagram

公式リンク：公式ドキュメント（Instagram Platform）

公式リンク：公式ドキュメント（Threads API）

Markdown版（AI向け原版）

AdSense Management API v2。サイト審査ステータスと収益レポートの読み取り。

Analytics Data API v1beta。ページ別アクセス数の読み取り。

公式リンク：公式MCPサーバー（Google Analytics）

状態：条件付き（仕様検証済み・未接続。Muse の自作登録はドメイン跨ぎで不可。ただし Google 公式の Analytics MCP サーバー（ADC認証）という公式ルートがある）。

楽天（楽天ウェブサービス）

Markdown版（AI向け原版）

楽天ウェブサービス。商品検索・ジャンル・ランキングなどの公開API群。アプリID＋アクセスキー方式（1リクエスト/秒が目安）。

状態：条件付き（技術的な壁はないが、利用規約第10条が「楽天アフィリエイト以外の収益化」と「特定の人だけがアクセスできる環境での使用」を原則禁止しており、個人専用エージェントは楽天の明示的許可が条件）。

Slack

Markdown版（AI向け原版）

Slack Web API。メッセージの読み取り・投稿など200超のメソッド。アプリの作成は api.slack.com/apps から。

公式リンク：アプリ作成（Slack API）

状態：条件付き（公式コネクタなし。認可・トークンとも slack.com 同一ホストで Google 型の壁は当たらないが、カスタム登録は未検証。確実なのは発行済みボットトークン（xoxb）の直接渡し）。

X

Markdown版（AI向け原版）

X API v2。投稿やユーザーの読み取り、投稿の作成など。

状態：条件付き（二重の壁：認可（x.com）とトークン（api.x.com）の分離でユーザー権限の登録は不可＝読み取り専用Bearerだけ作れる。さらに2026年2月から pay-per-use 従量課金に移行し、無料の読み取り枠が消滅）。

Yahoo! JAPAN

Markdown版（AI向け原版）

Yahoo!デベロッパーネットワーク。ショッピング情報検索・YOLP（地図／ローカル）・テキスト解析・YConnect（ID連携）。

公式リンク：公式開発者ポータル（Yahoo!デベロッパーネットワーク）

状態：条件付き（アプリID方式のAPIは作れる。店舗系ショッピングAPIとYConnectは条件付き。YOLPのデータを生成AIへ入力・学習利用するのは規約で禁止（2026年11月改定）、クレジット表示も義務）。

GitHub App連携の限界

Markdown版（AI向け原版）

App連携からはリポジトリ作成と .github/workflows/ への書き込みができない（403）。ウェブ画面でやるのが回避策。

Muse の OAuth 単一ドメイン規則

Markdown版（AI向け原版）

自作コネクタ登録では全エンドポイントが同一ドメイン必須のため、Google の API は軒並み登録不可。その理由と迂回路。

AdSense と AIクローラー

Markdown版（AI向け原版）

GitHub カスタムコネクタ（トークン方式）の実測
